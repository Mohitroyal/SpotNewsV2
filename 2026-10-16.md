## 1. Executive Summary

This document provides a detailed technical log of all fixes, optimizations, asset pipelines, and mobile application builds completed on **October 16, 2026**.

The primary focus of this engineering sprint was solving two critical production issues:
1. **Push Notification Icon Fidelity**: Eliminating the solid black square inside the Android notification header badge and replacing it with the crisp, transparent Spot News / RTI Express emblem.
2. **Video Clipping Generation & Feed Playback**: Fixing the "Video Placeholder" bug where uploaded videos failed to render into clipping cards and failed to play in the mobile feed.

---

## 2. Issues Addressed & Root Causes

| # | Reported Issue | Root Cause | Resolution |
|---|---|---|---|
| 1 | **Blue circle with black square in Android notification header** | Previous `ic_stat_logo.png` assets had solid opaque square corners (`alpha = 255`). Android notification systems treat opaque pixels as silhouettes; hence, an opaque square rendered as a solid black block inside the `#015BB3` tinted circular badge. | Re-generated all `ic_stat_logo.png` and `ic_stat_icon.png` drawables with 100% transparent backgrounds (`alpha = 0`) and clean white silhouettes. Cut out inner emblem details so the brand blue shines through. |
| 2 | **Shrunken / warped app launcher icons on Android 12+** | `mipmap-anydpi-v26/ic_launcher.xml` and `ic_launcher_round.xml` applied redundant `android:inset="16.7%"` on already-padded foreground assets, shrinking the adaptive icon twice into a tiny square. | Removed redundant insets; set adaptive backgrounds to `@color/ic_launcher_background` (`#FFFFFF`) and foreground to `@mipmap/ic_launcher_foreground`. Updated legacy mipmap launcher icons with full-resolution assets. |
| 3 | **Unwanted in-app popup notifications** | In-app notification banner component was actively rendering inside `App.tsx` on foreground messages, cluttering the screen when the user desired standard system drawer notifications. | Removed in-app notification popup overlay from `src/App.tsx`; notifications now route cleanly to the native Android notification shade. |
| 4 | **"Video Placeholder" gray box on clipping cards** | `generationService.generate` in `src/services/generation.service.ts` omitted `video_url` from the POST body sent to `/v1/generate`. The backend received `video_url = None` and fell back to `https://via.placeholder.com/800x600.png?text=Video+Placeholder`. | Updated `generation.service.ts` to include `video_url`, `videoUrl`, `reporter_image`, `heading_bg`, `border_color`, and `image_layout` in the API payload. |
| 5 | **Video not playing in news card feed** | `NewsDetailCardStack.tsx` only checked `item.video_url` and omitted `item.mp4_url`. Additionally, because `video_url` was missing on the backend, FFmpeg video generation was bypassed and `mp4_url` was `None`. | Updated `NewsDetailCardStack.tsx` to resolve `videoUrl` from `item.mp4_url`, `item.mp4Url`, `item.custom_layout?.mp4_url`, and `item.custom_layout?.mp4Url`. Updated backend to extract thumbnail frames from the video and encode the MP4. |
| 6 | **Database missing `mp4_url` column** | The `clippings` table in Supabase lacked the `mp4_url` column, throwing SQL errors during clipping completion. | Added `mp4_url` column to Supabase `clippings` table with graceful exception handling and transaction rollback safety in `clipping_views.py`. |
| 7 | **Render 512MB RAM Out-Of-Memory (OOM) during video encoding** | Default FFmpeg video composition buffered high-framerate frames and multi-threaded queues, risking memory limits on Render's 512MB container. | Optimized FFmpeg encoding: single thread (`-threads 1`), 24fps (`fps=24`), low buffer (`-bufsize 1M`, `-maxrate 1.5M`), zero latency (`-tune zerolatency`), no B-frames (`-bf 0`), and `-preset ultrafast`. |


### 3.3 Backend Services & Video Processing
- **`spotnews_django/core/clipping_views.py`**:
  - Added dual key checking `data.get("video_url") or data.get("videoUrl")`.
  - Injected transparent 1x1 PNG for hero box calculation when a video is present without static images.
  - Video composition pipeline with low memory profile:
    ```python
    cmd = [
        ffmpeg_exe, "-y",
        "-loop", "1", "-i", temp_bg_video,
        "-i", temp_video,
        "-filter_complex",
        f"[1:v]fps=24,scale={w}:{h}:force_original_aspect_ratio=increase,crop={w}:{h}[vid];[0:v][vid]overlay={x}:{y},pad=ceil(iw/2)*2:ceil(ih/2)*2[outv]",
        "-map", "[outv]", "-map", "1:a?",
        "-c:v", "libx264", "-preset", "ultrafast", "-tune", "zerolatency",
        "-bf", "0", "-threads", "1", "-max_muxing_queue_size", "1024",
        "-bufsize", "1M", "-maxrate", "1.5M", "-crf", "26",
        "-c:a", "aac", "-b:a", "96k", "-shortest", "-pix_fmt", "yuv420p",
        temp_mp4
    ]
    ```
- **`spotnews_django/core/services/render_service.py`**:
  - Video thumbnail frame extraction using FFmpeg pipe when static images are absent, preventing fallback to "Video Placeholder".
